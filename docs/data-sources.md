# VALORANT data sources

This GitHub Pages version is a static site. It does not make application API calls, scrape data providers, or bundle a professional match database. Player-entered values remain in the browser. For hosted pro statistics, follow the source link in the app to VCT Reference.

## Researched sources

| Source                                                                  | Data and access notes                                                                                                                                                                                                                                                                                                        |
| ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [VCT Reference dataset](https://vct-reference.com/dataset)              | Downloadable DuckDB with tier-one VCT match, map, round, and player-map records since 2021. The publisher describes it as free to use with attribution. Coverage varies by region and stat block; consult the [methodology](https://vct-reference.com/methodology) and gate missing stats rather than treating them as zero. |
| [Riot Developer API](https://developer.riotgames.com/docs/valorant)     | Official player match APIs are opt-in and are not a general historical VCT archive. A production integration would need to meet Riot's registration, consent, and use policies.                                                                                                                                              |
| [Riot Esports Data / GRID](https://riotesportsdata.com/en-us/valorant/) | Official granular tournament data is available through GRID. Current access is commercial/partner based, so it is not part of this static site.                                                                                                                                                                              |
| [VLR.gg terms](https://www.vlr.gg/terms)                                | Automated scraping and systematic collection require written permission. The site is linked only as a manual research source.                                                                                                                                                                                                |
| [rib.gg terms](https://rib.gg/terms)                                    | Match and player statistics are useful for manual review. Do not scrape at a disruptive rate or bypass access controls.                                                                                                                                                                                                      |
| [THESPIKE stats](https://www.thespike.gg/valorant-stats)                | Public match and player pages are available for manual reference; no supported public bulk export was identified.                                                                                                                                                                                                            |
| [Liquipedia API](https://liquipedia.net/api)                            | Tournament data may be available through an approved API account; this project has no API credentials.                                                                                                                                                                                                                       |

## Static hosting limits

GitHub Pages serves generated files and cannot run this project's Express API or query a DuckDB file on the server. The app therefore keeps personal analysis client-side and links to VCT Reference for professional archive search. It makes no external requests as part of analysis.
